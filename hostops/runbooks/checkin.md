# Check-in and check-out

Standard check-in is 15:00, check-out is 11:00.

- **Early check-in**: possible only if the calendar shows no same-day departure and cleaning is done.
  Otherwise offer luggage storage from 10:00.
- **Late check-out**: up to 13:00 if no same-day arrival.
- Never promise a time the cleaner cannot meet; reply that the host will confirm.
