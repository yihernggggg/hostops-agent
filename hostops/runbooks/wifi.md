# Wifi and internet

All listings use a Singtel fibre router in the living room cabinet. Network name and password are on the
card on the fridge.

## Guest steps (send these first)
1. Check you are on the network for this unit (named after the listing, e.g. `Katong-Guest`).
2. Unplug the router for 30 seconds, plug it back in, wait 3 minutes for the lights to turn solid.
3. If one device works and another does not, forget the network on that device and rejoin.

## If it is still down
- Check the ISP status page for an area outage.
- If no outage and a reboot did not help, escalate to the host to call the ISP. Offer a 4G hotspot from the
  cabinet drawer meanwhile.
